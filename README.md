# SLTB-M-Commerce-Bus-Ticket-Booking-Customer-App-Android
Developed an M-Commerce Mobile Application (Android) with Firebase database for the Sri Lanka Transport Board (SLTB) to enable digital bus ticket booking, secure payments, and real-time live bus tracking.

Developed an M-Commerce Mobile Application (primarily for Android) for the Sri Lanka Transport Board (SLTB) to revolutionize public transport ticketing. The app enables passengers to search, select, and book bus tickets digitally , featuring secure payment integration , digital ticket management with QR codes , and real-time live bus tracking. The project also included building a comprehensive Admin Dashboard for SLTB to manage schedules, fares, and analytics.
